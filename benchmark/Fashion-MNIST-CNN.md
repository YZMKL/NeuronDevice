
## Fashion-MNIST CNN 网络结构

### 基本信息

- 输入：28×28×1（灰度）
- 输出：10 类（T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot）
- 默认配置：`conv_channels=[32, 64]`, `fc_sizes=[128]`, `dropout=0.0`

### 详细网络架构

#### 1. 卷积部分（Convolutional Layers）

```
输入: [batch_size, 1, 28, 28]

┌─────────────────────────────────────────┐
│ 卷积块 1 (Conv Block 1)                 │
├─────────────────────────────────────────┤
│ Conv2d(1 → 32, kernel=3×3, padding=1)   │
│   输出尺寸: [batch, 32, 28, 28]         │
│ ReLU 激活                                │
│ MaxPool2d(kernel=2×2, stride=2)         │
│   输出尺寸: [batch, 32, 14, 14]         │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 卷积块 2 (Conv Block 2)                 │
├─────────────────────────────────────────┤
│ Conv2d(32 → 64, kernel=3×3, padding=1)  │
│   输出尺寸: [batch, 64, 14, 14]         │
│ ReLU 激活                                │
│ MaxPool2d(kernel=2×2, stride=2)         │
│   输出尺寸: [batch, 64, 7, 7]           │
└─────────────────────────────────────────┘

展平 (Flatten): [batch, 64 × 7 × 7] = [batch, 3136]
```

#### 2. 全连接部分（Fully Connected Layers）

```
输入: [batch_size, 3136]

┌─────────────────────────────────────────┐
│ 全连接层 1 (FC Layer 1)                 │
├─────────────────────────────────────────┤
│ Linear(3136 → 128)                      │
│ ReLU 激活                                │
│ Dropout (如果 dropout > 0)              │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 输出层 (Output Layer)                   │
├─────────────────────────────────────────┤
│ Linear(128 → 10)                        │
│   输出: [batch, 10] (未归一化的logits)  │
└─────────────────────────────────────────┘
```

### 特征图尺寸变化流程

```
输入图像:     28 × 28 × 1
    ↓
Conv1 (32):   28 × 28 × 32  (padding=1保持尺寸)
    ↓
ReLU:         28 × 28 × 32
    ↓
MaxPool2d:    14 × 14 × 32  (下采样2倍)
    ↓
Conv2 (64):   14 × 14 × 64  (padding=1保持尺寸)
    ↓
ReLU:         14 × 14 × 64
    ↓
MaxPool2d:    7 × 7 × 64    (下采样2倍)
    ↓
Flatten:      3136 (64 × 7 × 7)
    ↓
FC1 (128):    128
    ↓
ReLU:         128
    ↓
FC2 (10):     10 (输出类别logits)
```

### 参数统计

- 卷积层参数：
  - Conv1: `1 × 32 × 3 × 3 + 32 = 320`
  - Conv2: `32 × 64 × 3 × 3 + 64 = 18,496`
- 全连接层参数：
  - FC1: `3136 × 128 + 128 = 401,536`
  - FC2: `128 × 10 + 10 = 1,290`
- 总参数：约 421,642

### 设计特点

1. 卷积层：使用 3×3 卷积，padding=1 保持空间尺寸，ReLU 激活
2. 池化：每个卷积块后接 MaxPool2d(2×2)，将特征图缩小 4 倍
3. 全连接：单层隐藏层（128），最后输出 10 类
4. 激活函数：ReLU
5. 正则化：可选 Dropout（默认关闭）

### 与 MNIST CNN 的关系

`FashionMNISTStandardCNN` 与 `MNISTStandardCNN` 结构相同，因为：

- 输入尺寸相同（28×28 灰度）
- 类别数相同（10）
- 任务复杂度相近

该结构适合 Fashion-MNIST，能有效提取纹理和形状特征。
